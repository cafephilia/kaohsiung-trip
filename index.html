🏨 호텔 후보

후보 4곳입니다. 가격은 트립닷컴 12/10–13 호텔만 따로 예약한 3박 총액(객실 1개, 성인 2명, 세금 포함)이고, 항공 포함 묶음가는 카드의 주황색 칸에 있어요. 장단점은 트립닷컴 투숙객 리뷰를 요약했어요.

묶음가는 트립닷컴 묶음 화면에서 항공편을 바꾸고 해당 객실을 직접 골라 확인한 값이에요. 가는 편 추가 요금은 조회 시점마다 바뀌었지만(+₩49,000 → +₩58,400) 기본 항공편 가격도 같이 내려가서 총액은 1인 ₩150 정도만 달라졌어요. Sleepie는 더블룸 묶음가(₩616,350)만 확인했고 4인룸 묶음가는 확인하지 않았어요. 에버럭은 메이리다오 필터 목록 아래쪽에 있어요.

🔧 트립닷컴에서 같은 조건 만드는 법
  1. 항공+호텔에서 서울 → 가오슝, 12/10–12/13, 성인 2명, 객실 1개로 검색
  2. 항공편의 '더 많은 항공편 보기' → 가는 편 제주항공 11:00 선택 (1인 +₩49,000~58,400, 조회 시점마다 다름)
  3. 오는 편 트리니티 14:05 → 김포 17:55 선택 (+₩0) → '계속'
  4. 호텔 검색창에 '메이리다오'를 입력하고 호텔의 '선택' → 싱글침대 2개 객실(후 하우스 스탠다드 트윈, 더 클라우드 트윈룸, 에버럭 코지룸) 요금 선택
  • 묶음은 따로 예약할 때보다 2인 약 7만 원 쌉니다. 항공편이 같고 왕복 위탁 수하물 15kg이 포함돼 있어요.
  • 후 하우스는 조식 포함 요금이 1인 +₩3,000밖에 안 돼서 조식 포함을 추천해요. 따로 예약하면 조식이 1인 1회 ₩11,177이에요.
  • 호텔 취소 조건과 별개로 항공권 변경·환불 규정은 결제 전에 '규정 및 수하물'에서 꼭 확인하세요.
  • 트립닷컴 신규회원 호텔 할인코드(최대 ₩13,000)와 카드사 제휴 코드를 같이 쓸 수 있는지도 확인해 보세요.

✅ 예약 전 체크리스트

  • 트윈룸 재고가 적어요. 후 하우스·더 클라우드·에버럭·Sleepie 모두 조회 시점에 "1~2개 남음"으로 표시됐어요.
  • 금·토요일 밤이 끼어 있어 주말 요금이 적용돼요. 무료 취소 객실로 먼저 잡아 두면 안전해요.
  • 저가항공은 위탁 수하물(15kg 등) 포함 여부와 기내 수하물 무게 제한을 확인하세요.
  • 항공권 2장을 따로 사면 결항 시 연결 보호가 안 돼요. 여행자보험의 항공기 지연 보장을 확인하세요.
  • 입국 전 대만 온라인 입국신고서를 작성하세요. 한국 여권은 90일 무비자예요.
  • 콘센트는 110V, 11자형(A타입)이라 돼지코 어댑터가 필요해요.
